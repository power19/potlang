# PrepSmart - Healthy Food Prep & Calorie Tracker

A personal healthy food prep web app with recipes, calorie tracking, and daily meal planning.

- **Daily Goal:** 1,500 kcal
- **Diet Style:** Balanced / General
- **Features:** Recipe browser, calorie meter, meal planner, food log

## Usage

Open `index.html` in any modern browser. No build tools or server required.
